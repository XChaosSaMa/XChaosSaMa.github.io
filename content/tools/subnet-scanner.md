This is a personal script to install Arch on Termux with the AUR and Blackarch repositories. It will also install Xfce4 to have a functional desktop that you can use with VNCViewer.

Instructions:

    /// Clone repository

    > git clone https://github.com/XChaosSaMa/TermuxArch

    /// Give disk read permissions to termux

    > termux-setup-storage

    /// Move the downloaded script to the home directory

    > mv storage/downloads/TermuxArch.sh .

    /// Give the execution permit

    > chmod +x TermuxArch.sh

    /// Run it

    > ./TermuxArch.sh

    /// In VNCViewer

    Adress: localhost:1
